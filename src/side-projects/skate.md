Prototype made in Unreal Engine for a platformer designed around using a skateboard for different things based on
gameplay context.

For this project I've implemented modular movement system based around built-in Character Movement Component, learned
about creating animations inside the engine, implemented reusable combo system, tested some ideas for movement
mechanics and learned a lot about implementing dynamic audio using built-in MetaSounds plugin.
